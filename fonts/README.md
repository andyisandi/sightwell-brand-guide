# fonts

Both brand typefaces come from Adobe Fonts — nothing needs to live in this folder.

- Freight Text Pro  — already in kit qcx2rwd
- Pragmatica Extended — add it to kit qcx2rwd (weights 400 + 500); the CSS already
  asks for `pragmatica-extended` first, so it activates automatically.

Until Pragmatica Extended is added to the kit, labels use the embedded
Archivo Expanded stand-in.
